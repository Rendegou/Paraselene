## 关键设计决定

1. **隔离下沉到 DDL**：`CHECK(space!='novel' OR work_id IS NOT NULL)` + `CHECK(space='novel' OR work_id IS NULL)`——"小说角色的话永远不能当成用户个人经历"由数据库强制，不靠 API 自觉。
2. **无全空间查询入口**：list 必须按 space 过滤，全局视图若需要应是显式产品决策重新评审（spaces.rs 模块文档写明）。
3. **memory_sources 不加 FK**：出处链要在会话被清理/重导入后仍可展示，级联删除会抹掉用户确认过的证据。
4. **链接单向可见**：from 侧见出链（actor=user），to 侧无反向；跨空间链接只允许 `link_memories` 显式写入（Goal §4.2 红线入注释）。
5. **瘦身组合（测量驱动）**：实测 tool 角色占文本量 78%（322MB/412MB）→ tool 不进 trigram FTS（精确词检索仍由 unicode61 全量覆盖）；单条消息入 FTS 文本截 4096 字符（原文完整保留 messages 表）；trigram 表从 external content 改独立表（前缀索引与 rebuild 语义不兼容）。

## 2026-09-27 正式搜索入口接线复核

- 复核 `crates/memory-core/src/storage/search.rs` 发现：历史 `retrieval_eval.rs` 直接查询 `message_fts_trigram`，但应用使用的 `Database::search()` 始终查询 `message_fts`（unicode61）。因此历史 24 题召回数字只证明评测变体，不证明当时的正式搜索 API。旧单测还把句中中文词返回 0 固化为“已知限制”。
- 在隔离副本新增最小回归：写入用户消息“幻月桌宠的记忆引擎”，用 `Database::search()` 查“记忆引擎”。修复前实际执行 `cargo test -p paraselene-memory-core --lib 中文句中片段应进入正式搜索结果 --target-dir D:\paraselene\target -- --nocapture`，退出码 1，结果 `left: 0 / right: 1`。同一库的 trigram 表已有命中测试，故断点在正式 API 的索引选择，不在导入或建索引。
- 正式查询现在对含非 ASCII 字母且长度足够的输入复用已评测的 3–6 字 n-gram OR 查询、`message_fts_trigram` 与 `ORDER BY rank`；纯 ASCII 和不足三字的输入保留 unicode61 前缀搜索。表名只从代码内两个常量选择，用户文本仍通过 SQL 参数绑定。修复后同一目标测试退出码 0；`cargo test -p paraselene-memory-core --lib 中文 --target-dir D:\paraselene\target -- --nocapture` 2 项通过；全 memory-core 49 项通过。回归还检查命中消息 ID、片段高亮和实际 MATCH 表达式。
- 上述回归测试使用内存库合成文本。随后在正式仓库执行 `cargo test --workspace --quiet`，退出码 0，共 93 项通过（7+1+3+33+49）；`cargo build -p paraselene` 退出码 0。评测器新增 `--summary-only`，只打印聚合数字，不打印问题、来源正文或文件名。
- 在正式仓库执行 `cargo run -p paraselene-memory-core --example retrieval_eval -- D:\paraselene\data\retrieval-testset.json D:\paraselene\target\import-smoke --summary-only`，退出码 0；题集 24 题，库 100 会话/772 消息，映射缺失 0。正式 `Database::search()` 与独立 trigram 查询结果一致：recall@5 **23/24（96%）**，top-1 **22/24（92%）**；top-1 片段含标注 anchor **4/24（17%）**，top-1 消息全文含 anchor **15/24（62%）**，top-1 会话含 anchor **20/24（83%）**。这复验了 G05 的召回与出处数字，但短片段不足以承担 G08 的原文证明，旧想法卡片必须能展开确切原文/会话位置。两字中文句中查询仍受 unicode61 前缀限制，应在后续题集中单列。
