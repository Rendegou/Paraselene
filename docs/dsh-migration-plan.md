# dsh 迁移计划

更新：2026-10-23 · 执行状态见 [任务看板](progress-checkpoint.md) · 决策见 [ADR-0003](adr/0003-dsh-runtime-adapter.md)

## 目标与范围

将幻月的通用 Agent 执行能力逐步交给 dsh，前端继续使用 React + TypeScript。幻月独立发行，拥有自己的交互、数据和授权规则。适配层隔开运行时协议与业务代码，插件负责把 dsh 的任务执行接到幻月受控能力上。

本轮从迁移计划、运行时契约和桥接验证开始。保留现有 Tauri 桌宠、SQLite 记忆库、角色、原生凭据和模型实现；不迁移私人语料，不改变数据库格式。小说编辑器及 Python 沙箱的历史未完成项不因这次迁移变为完成。

首个验证闭环是：限定空间请求 → 展示外发内容 → 用户确认 → 流式回答 → 明确完成或停止。后续再接有出处的检索与业务写入。

## 责任边界

```text
React / TypeScript 界面
  → 幻月运行时契约
      → 现有 Tauri 模型适配器（迁移基线）
      → dsh 适配器 → 自定义 profile / 桥接插件（实验）

幻月领域接口 → SQLite、出处、小说正稿、学习记录
dsh 自有业务插件 → 经过授权与空间校验的幻月领域接口
dsh 自有 provider → 原生模型出口 → DeepSeek 官方 API（M03）
```

界面和业务代码不读取 dsh 内部会话格式。插件不直接操作幻月数据库。执行日志与长期记忆分工明确：dsh 记录执行，幻月记录用户确认过的业务事实；执行恢复不能重复提交业务结果。

## 阶段与验收

| 阶段 | 交付 | 验收后才能进入的能力 |
|---|---|---|
| M00 计划与 ADR | 本计划、ADR-0003、当前基线与回退规则 | 有明确范围和负责人 |
| M01 运行时契约 | 独立 TypeScript 类型与接口、现有 Tauri 适配器、界面通过契约调用、契约测试 | 更换运行时无需改写页面逻辑 |
| M02 dsh 桥接验证 | 固定 dsh 版本、自定义 profile、桥接协议、离线运行测试 | 证明能启动、驱动、收流、取消及回收真实 dsh 进程 |
| M03 受控模型出口 | 原生凭据、最终请求冻结与预览、一次性确认、发送前空间重检 | 允许 dsh 发起真实模型请求 |
| M04 业务工具 | 受控记忆检索与出处、试写提案、学习接口 | 模型可以按授权使用幻月数据和业务能力 |
| M05 Windows 验收 | 进程打包、故障恢复、性能对照、完整原生闭环 | 切换默认后端，并逐步退役重复实现 |

M00–M02 可以在不接触真实 Key 和私人记忆的条件下推进。M03/M05 未通过前，产品默认仍走现有 Rust 模型实现；实验入口不能伪装成已完成的 dsh 后端。M03 的出口约束同时适用于 M04 新增工具产生的后续请求。

### M00：固定迁移基线

- 幻月起点：`aa3eed0930d1c8aa7ff0c572ca53e0310022a29c`。
- dsh 检查基线：`0.2.1-rc.2`，提交 `687f282e8625c6b8d11ff58211a90524be2e4317`。
- 插件与运行时采用精确依赖及锁文件，记录 Node.js 22、包管理器和平台条件。升级先单独验证，不跟随 `latest` 自动切换。
- 检查现有构建和类型检查；失败明确区分历史问题、环境限制和本轮回归。测试命令、退出码与关键结果写入本轮证据。

### M01：抽离运行时契约

- 定义幻月自己的请求、空间、预览票据和流事件，Tauri 与 dsh 细节只留在适配器内部。
- 现有模型请求先接回同一接口；保留后端持有预览与一次性消费的现有语义，前端不能自行修改确认后的内容。
- 明确能力声明。不支持工具执行、运行中取消或持久恢复时，接口显式表达，不能用丢弃前端事件冒充后端取消。
- 测试预览不触发发送、确认发送只传票据、事件映射、错误传播、重复或未知票据、未支持能力的行为。跨进程安全规则仍由后端执行，TypeScript 类型不是授权边界。
- 验收要求：类型检查、运行时契约测试和前端构建通过；以契约测试证明页面通过新接口仍可驱动现有实现。原生 UI 操作另外验收。

M01 使用 Node.js 22（最低 `22.19.0`；本轮云端 `22.21.1`）、pnpm `11.25.0` 和 PowerShell 7。在仓库根目录逐条执行：

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm typecheck:runtime
pnpm test:runtime
pnpm build
```

每条命令的实际退出码、关键输出和环境限制记录在 [M01 本轮证据](evidence/M01-20261023.md)。上述命令清单不代表已经通过，结果以该证据与看板为准。M02 的 `runtime/dsh` 是独立 package/workspace，使用自己的锁文件和验证命令，不由根目录 M01 安装替代。

### M02：验证 dsh 桥接

- 在独立目录与 Harness home 中启动固定版本 dsh，使用幻月自定义 profile；不复用开发者全局配置、插件目录或会话。
- 桥接只开放必要的运行、事件、取消和关闭方法。每次活动有可追踪身份，事件按所属活动分发；迟到事件、进程崩溃和 EOF 明确终止，不能报告假成功。
- 通过 dsh 公开 Agent 能力实现取消，不把 SDK 关闭整个运行时等同于已完成单次任务取消。
- 用合成文本和离线模型适配器验证真实 dsh 进程。该结果标为“运行时 REAL / 模型 SIMULATED”，不能报告真实 DeepSeek 调用通过。
- 不挂载生产凭据、日志上传、外部遥测和无关系统工具。离线配置是最小功能组合，不是任意第三方插件的安全沙箱。
- 测试启动失败、协议错误、流式输出、取消确认、结束后迟到事件、重复关闭及进程回收。仅有协议模拟测试不等于真实 dsh 启动通过。

本轮实现与运行命令见 [runtime/dsh/README.md](../runtime/dsh/README.md)，实际 9 项测试及探针结果见 [M02 证据](evidence/M02-20261023.md)。该独立包使用自己的锁文件，不进入前端生产构建或默认运行时选择。

### M03：接通受控模型出口

- dsh 不持有真实 Key。自有 provider 经原生服务读取系统凭据并发送，WebView 继续只获得设置状态。
- 在最终协议序列化边界冻结请求。用户看到的预览和请求绑定同一份内容，确认后消费一次性票据，发送前重新检查空间云开关。
- 覆盖普通轮次、工具结果后的轮次、重试、压缩摘要、标题生成和子 Agent；无法确定所属空间或作品的调用拒绝发送。取消待确认请求不得消耗模型调用。
- 关闭 `dsh_session_log` 与 `dsh_plugin_packages` 等额外请求字段，核对网络与遥测路径。默认日志上传即使不进入模型提示词，也属于外发内容。
- 验证修改预览、票据重放、预览后关云、等待确认时取消、压缩绕过、子 Agent 跨空间、网络中断及日志脱敏。
- 真实 API 验证只使用已配置且获授权的 Key 与少量合成输入；未配置时保持 NOT_RUN，不使用模拟输出代替。

### M04：接入领域工具

- 先开放只读检索。后端从可信任务上下文绑定空间、作品和已授权来源，再查询资料；模型传入的身份字段不能扩大范围。
- 检索返回少量证据与可打开出处，短摘要不能代替原文。跨空间链接由用户明确触发。
- 旧想法状态、个人事实、小说正稿与学习目标通过领域接口执行确认写入。试写先进提案区，重复执行或恢复不能重复采纳。
- 私人事实、小说台词、学习记录分别验证隔离；删除和纠正后，索引与后续模型上下文同步生效。
- 学习工具先接题目与确定性测试结果。执行用户 Python 代码仍以 ADR-0002 与 G13 隔离验收为前置条件，不开放 dsh 通用 shell 作为替代。

### M05：Windows 切换

- 在 Windows 11 / Node.js 22 / PowerShell 7 验证原生进程发现、启动、安装路径、中文路径、托盘退出与更新后的清理。按需启动，关机或退出不遗留子进程。
- 对照现有实现实测冷启动、驻留内存、CPU、空闲模型请求与扫描计数。记录硬件、系统、版本、采样命令，再确定性能门槛；Linux 数值不充当 Windows 验收。
- 跑完整“预览—确认—流式输出—停止—重启恢复”与 G15/G16 原生操作，再验证有出处记忆的 G04–G08。小说、学习及安装包各自按原 Goal 验收。
- 明确默认后端切换与回退方式。停止 dsh、作废待确认请求，以旧实现重新预览；不自动重试云请求或双写。
- 确认迁移通过后再删除重复 Agent 代码。原生凭据与记忆服务的去留依据实际需求另行决定。

## 证据与状态口径

| 证据 | 可以证明 | 不能证明 |
|---|---|---|
| 契约单测，模拟传输 | 接口、状态与事件行为 | Tauri 原生 IPC 或真实 dsh 已通 |
| 真实 dsh + 离线模型 | profile、插件组合与运行桥接 | 真实 API、Keyring、隐私出口已通过 |
| 类型检查与 Web 构建 | TypeScript 一致性与前端打包 | Windows 桌宠可用或资源达标 |
| Windows 原生实测 | 对应版本与机器上的明确验收项 | 其他未运行的产品模块 |

REAL 用于真实执行且有命令记录的部分，SIMULATED 用于模拟模型或传输，PLANNED 用于尚未实现的能力。历史测试数量、召回率和资源数据不自动沿用。本轮证据在 `docs/evidence/`，实际命令由执行者记录并在看板链接。

## 回退与范围控制

本轮不引入数据库格式迁移，旧实现保留。适配器切换只能发生在空闲且没有待确认请求时；无法确认任务是否停止时，先终止并回收运行时，向用户明确报告未完成，不转入另一引擎自动重发。

若上游扩展点无法满足完整外发约束，先缩减自动摘要、标题、子 Agent 等功能范围，保留已验证的最小组合。确需修改上游时，先记录具体缺口与可上游化改动，不将实验补丁自动扩展为长期深 fork。
