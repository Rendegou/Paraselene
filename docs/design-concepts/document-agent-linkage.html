雾中的灯塔

编辑稿 · 讨论与修改对应到具体段落

雾是在傍晚漫上来的。

起初只是水面上很薄的一层，像有人把一封没有写完的信，轻轻铺在了海上。等林雾走到白塔港尽头，整座灯塔只剩下一点模糊的轮廓。

她把那封信又读了一遍。

纸上的字迹已经洇开，唯独最后一句还清晰得像刚刚写下：不要相信第十三声钟响。

“你还是来了。”

第5段

站在灯塔的阴影里，肩头落着细密的水珠。他没有撑伞，右手握着一枚旧铜钥匙。林雾注意到，钥匙柄上的纹路，与信封封蜡上的裂纹一模一样。

她没有问他为什么在这里。

有些问题，一旦问出口，就再也无法假装自己不知道答案。
