## 实现与范围

- **REAL（代码）**：设置页选择 ChatGPT、Codex、Kimi、Claude 来源，通过原生系统选择器选择单个文件。原生进程只读解析，向 WebView 返回文件名、识别格式、会话/消息/失败计数、最多 5 条解析提示和最多 2 条各 360 字的消息抽样，不返回完整本机路径。
- **REAL（代码）**：用户按“确认导入”后，一次性票据才可触发托管副本写入及扫描索引；取消、更换来源、再选文件会放弃旧预览。导入结果分别报告新增、重复与失败。空白旧想法页有前往导入的入口。
- **REAL（限制）**：文本文件读取上限 16 MiB；ChatGPT Markdown ZIP 压缩包 64 MiB、2000 条目、总解压文本 128 MiB，逐条目最多 16 MiB。ZIP 不向磁盘解压，非 Markdown 条目不处理；解压流实际字节也受限。
- **SIMULATED**：合成文本与 ZIP 测试证明预览不写来源或索引、确认才写入、重复确认不生成第二份会话，以及坏条目不阻断好条目。
- **PLANNED**：原生窗口中操作选择器、取消、预览、确认的演示；目录级授权、持续同步及其他导出格式的真实样本复验。
