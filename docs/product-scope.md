# 幻月当前产品目标

更新：2026-10-23。本文件唯一维护当前目标、优先级与非目标；[当前状态](progress.md)维护实现和验证结果。[架构合同](engineering/architecture-contracts.md)约束数据含义，[前端规范](engineering/frontend-standards.md)与[设计系统](../DESIGN.md)约束工程与交互。目标存在不代表功能已经验收。

## 产品与当前阶段

幻月是面向小说作者的 Windows 写作工作台，使用 Flutter 展示层与 Rust 本地业务核心。核心体验是在持续可编辑的稿件上查阅资料、围绕选段讨论、审阅候选，并明确区分编辑稿、保存和正式版本。

当前阶段优先稳定小说写作闭环及其前端/Agent 开发合同。既有记忆、想法、人物、RPG、学习与桌宠入口保留，按独立能力记录欠项；不把历史多模块全部迁移作为每张前端任务的隐含目标。涉及范围改变时修改本文件并给受影响任务明确结论。

当前开发和验收继续使用受控合成工作区。作者数据接管、真实模型请求和正式发布各有独立入口与验收条件，不由“页面已实现”自动获得许可。

## 用户结果与需求编号

- **W01 工作区连续性**：作者可以创建/选择作品、导航章节、查找和调整目录。切换前等待必要保存；失败保留原身份、内存稿和恢复入口，旧响应不覆盖新目标。
- **W02 正文编辑与保存**：输入、选择、剪贴板、撤销/重做保留精确原文；自动保存和 Ctrl+S 只保存编辑稿。确认章节才创建正式版本；回滚有明确目标与失败反馈。
- **W03 原位讨论**：选择正文后在原位展开讨论；收起/重开保留草稿、引用和运行态；失效选段仍可查历史。讨论界面与占位不进入正文、复制或导出。
- **W04 模型与候选**：完整展示待外发材料，明确确认后才发送；取消、失败、迟到响应可理解。采纳只更新编辑稿并可撤销，不自动确认正式版本，不自动把 AI 内容变成正史。
- **W05 资料与出处**：查阅、带入讨论和修改资料是独立动作；出处关联准确、过期状态明确，失败可恢复；不能用旧出处装饰新稿件。
- **W06 桌面交互与语言**：常规/窄窗、1×/2× 字号下核心操作可达；键盘焦点、菜单层级和 IME 互不抢占。UI 验证语言为 zh-Hans/en，RTL/伪长文案只作结构测试，不冒充已发布翻译。
- **W07 恢复与分发**：保存失败可重试或导出当前内存稿；可读导出与可恢复备份分开，取消不显示成功。关闭走同一个保存屏障；完整 bundle 的净机可运行证据独立验收。

每张较大任务关联上述需求编号，并把适用状态、输入/动作/预期与证据落到[任务合同](engineering/task-template.md)。不把一个需求编号当作整项已经完成。

## 本阶段非目标

- 不重做品牌、自动加入深色主题或宣布额外发布语言。
- 不随规范整理迁移状态框架、数据库、路由或扩充模型供应商。
- 不因为统一界面删除既有能力、改作者正文、放宽 CAS/hash/预览许可或存储来源防护。
- 不在普通前端任务中读写作者库、读取真实凭据、调用收费模型、安装发布包或进行数据接管。
- 不承诺断电后恢复尚未提交的内存稿；不把合成测试和本机 Release 构建当作全产品发布认证。

## 完成口径

**已实现**表示存在接线和可执行行为；**已验证**要求对明确源码提交/工作树执行适用验收；**可发布**还需要对应产物、视觉与原生矩阵、安装/数据边界和发布决定。三者分别记录，不能互相继承。

当前路线先完成文档/任务合同统一与已知菜单测试整改，再逐个收敛失败恢复、状态所有权、视觉基线和系统验收。具体队列、最近检查及未测项始终见[当前状态](progress.md)，本文件不重复测试数量。
