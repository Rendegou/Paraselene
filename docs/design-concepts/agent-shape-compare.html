第三章 · 灯塔来信

灯塔来信

海雾是在凌晨退去的。

林汐沿着防波堤往前走，潮水在石缝里留下细碎的白沫。灯塔比她想象中更旧，门口的铁链已经锈成了暗红色。她从外套内袋取出钥匙。

门没有锁。

“你比我想的来得早。”

闻舟站在门口，手里拿着两杯还冒热气的咖啡。他的目光落在那封信上，又很快移开。

“我父亲来过这里？”她问。

“很多人都来过。”

林汐把信翻过来。背面有一道很浅的折痕，像有人反复捏住同一个地方。她把它放进外套，没让闻舟看见信封上的字。
