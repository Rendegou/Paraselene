The exercise HTML/CSS/JavaScript originated in the Paraselene project.
Migration changes: isolated HTTPS origin, English UI copies, separate native
host with no web messaging or host objects. Learner code runs only in a Worker.

Microsoft WebView2 SDK 1.0.2903.40 is downloaded separately by
scripts/prepare-learning-sdk.ps1 and checked against a pinned SHA-256.
Its license is included in the SDK NuGet package. The browser runtime is a
separate Microsoft Edge WebView2 prerequisite; the application does not install it.
