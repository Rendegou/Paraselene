# 当前方向：小说客户端，前端优先

更新：2026-10-12。用户明确调整：先放弃桌宠形态，把小说创作前端做出来；以可点击引用把 AI 协作、人物、地图和世界观连接起来。此方向覆盖此前的多功能陪伴 Agent 排期。

## 唯一目标

做一个作者愿意长时间使用的小说创作客户端。成功路径：找章节 → 写正文 → 引用设定讨论 → 审阅修改 → 作者采纳 → 点击出处继续深入。

不是在旧卡片里增加入口。默认打开普通、可调整大小、非置顶的创作窗口；桌宠隐藏，通知状态轮询不再启动。旧资料与设置保留在托盘次级入口。

## 三个交付阶段

1. **前端体验（本轮）**：目录与正文，浅灰外框与暖白纸面。共写挂在目标段落之后，资料按需查看，全章讨论主动打开抽屉；保留人物/世界/地图编辑、精确原文跳转、修改审阅、专注、预览保存与导出。独立三个设计场景使用合成素材，不读取现有预览。
2. **真实业务闭环（下一步）**：独立作品入口，新界面接现有 SQLite working copy、版本树、DeepSeek 外发预览与 patch。生成失败、过期修改、保存冲突明确可见。先拿一部小作品跑通。
3. **引用深入**：设定/地点/人物绑定不可变正文版本，点击引用和反向引用；Agent 只使用作者选定的上下文。先做手工关系，再评估自动提取。

不要再按 T05A–T05H 八阶段、全产品 G01–G20 并行展开。旧规格保留为工程边界和历史参考，不作为本轮必须全部交付的清单。
