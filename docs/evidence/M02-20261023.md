# M02：真实 dsh 进程与离线桥接验证

日期：2026-10-23 · dsh：`0.2.1-rc.2` · 代码：`runtime/dsh/`

## 范围与事实

- REAL：官方 CLI、自定义 profile、真实 Agent 循环、流式事件、定向取消、取消后继续、终止与进程回收。
- SIMULATED：自有离线 `LlmAdapter` 返回合成文本，不实现 HTTP，不使用真实模型或 Key。
- PLANNED：产品运行时适配器、可信空间授权、最终模型请求预览及原生凭据出口、持久化恢复、业务工具与 Windows 验收。

本实验未接入产品界面。现有模型后端仍为默认；数据库、私人资料、原生窗口和凭据均未迁移。

## 工具链与命令

Linux x64、PowerShell 7.5.4、Node.js 22.21.1、pnpm 11.25.0。沿用 [M01](M01-20261023.md) 的 Node 22 CLI 执行方式，在仓库根目录运行：

```powershell
$env:PATH = "/workspace/tools/node22/bin:" + $env:PATH
& /workspace/tools/node22/bin/node /opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules/pnpm/bin/pnpm.mjs --dir runtime/dsh install --frozen-lockfile
& /workspace/tools/node22/bin/node /opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules/pnpm/bin/pnpm.mjs --dir runtime/dsh test
```

独立探针另在 `runtime/dsh` 工作目录执行 `node scripts/probe.mjs`（实际使用上述 Node 22 的绝对路径）。普通工具链的复现命令见 [运行说明](../../runtime/dsh/README.md)。

## 断言覆盖

1. 拒绝未知空间、缺失小说作品归属、凭据和路径配置字段。
2. 校验协议版本、身份与输入长度，错误不回显拒绝的正文。
3. 合法请求保留显式空间；取消只指向一个活动 ID。
4. profile 只挂载 7 个必要核心服务与自有测试 provider/bridge。
5. 真实 dsh 流式输出、重复 ID / BUSY 拒绝、定向取消、随后执行和正常 shutdown。
6. 空闲 EOF 正常退出并删除临时 Harness home。
7. 创建同批立即取消只终止一次，之后仍可执行。
8. 模型收流期间 EOF 取消并回收进程。
9. 非法 JSON 安全拒绝；65,537 bytes 未结束行触发错误并退出 1。

## 验证发现与修复

第一版收流、取消和后续执行通过，但显式 shutdown 超过 5 秒而失败，未计为通过。原因是桥接插件把清理注册到普通 `dispose` 事件，该版本 Cordis 并不通过此事件执行生命周期清理；stdin 句柄因此仍存活。改为 `ctx.effect` 返回异步清理函数后，正常关闭、EOF 和运行中取消均通过。没有修改上游代码，也没有用强杀结果冒充正常完成。

父进程仍保留 EOF → SIGTERM → SIGKILL 的有界回收路径，测试专用 home 在退出后删除。scope 当前只做协议格式校验；真实用户与作品授权留给幻月受信服务，不能把这一实验直接开放给私人记忆。

## 结论

M02 离线进程桥接验证通过。该结果证明公开插件扩展点能够驱动真实 dsh 并实现单活动取消；不证明真实模型出口、长期记忆、持久恢复或 Windows 产品切换已经完成。
