## 可复跑文档入口检查

在 `D:\MyAgent\paraselene-work` 使用PowerShell7执行下段；只读取指定Markdown和检查路径存在，不读取凭据/私人正文。

```powershell
$files = @('README.md','AGENTS.md','docs/engineering/project-map.md',
  'docs/engineering/code-standards.md','docs/novel/README.md',
  'docs/novel/open-source-research.md','docs/novel/product-spec.md',
  'docs/novel/context-and-storage.md','docs/novel/implementation-plan.md',
  'docs/adr/0003-longform-novel-workbench.md',
  'docs/handoff/20261003-novel-first-kimi.md','docs/development-direction.md')
$missing = @()
foreach ($file in $files) {
  $absolute = (Resolve-Path -LiteralPath $file).Path
  $text = Get-Content -Raw -LiteralPath $absolute
  $text = [regex]::Replace($text, '(?ms)^```.*?^```\s*$', '')
  foreach ($match in [regex]::Matches($text, '\[[^\]]+\]\(([^)]+)\)')) {
    $target = $match.Groups[1].Value.Trim('<','>')
    if ($target -match '^(https?://|#|app://|thread://)') { continue }
    $target = ($target -split '#')[0]
    $resolved = [IO.Path]::GetFullPath((Join-Path (Split-Path $absolute) $target))
    if (-not (Test-Path -LiteralPath $resolved)) { $missing += "$file -> $target" }
  }
}
$missing
if ($missing.Count -gt 0) { exit 1 }
Write-Output 'DOC_CHECK:PASS'
```

未来T05A的统一入口可使用独立脚本执行这些检查。
