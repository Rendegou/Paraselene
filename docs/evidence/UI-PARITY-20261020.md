# 写作工作台视觉方案对齐（原 TS 版）+ 自绘导航栏并入默认界面

日期：2026-10-20。状态：IMPLEMENTED（代码与自动化门禁通过；真实窗口截图复看待用户确认）。
范围：`paraselene-flutter` 的写作工作台视觉层；不改 Rust、不改作者正文/数据库合同、不删功能。

## 1. 目标与边界

用户要求：基于原 `paraselene-work` 前端代码，把 Flutter 工作台做得“设计差不多”（不要求像素级一致）；
并把此前实现但默认关闭的自绘导航栏（M2-W `DesktopTitleBar`）与正式界面合并。

- 参考来源：`paraselene-work/src/features/studio/writing/NotebookTheme.css`、`NotebookChrome.css`、
  `NotebookToolbar.tsx`、`NotebookSidebar.tsx`、`ChapterHeading.tsx`、`NotebookMenus.tsx`。
- 不做：逐像素复刻（Flutter 与 DOM 文本排版不同）、替换系统字体文件、重做全部对话框交互。
- 不变量：作者正文仍由既有编辑会话/保存屏障负责；界面重排只读取 `WorkspaceController` 与 `EditorActionRegistry`。

## 3. 主要改动文件

- `lib/theme/workbench_theme.dart`：令牌 + 扁平 Material 组件主题（按钮、菜单、对话框、输入、滚动条、提示）。
- `lib/workspace/presentation/workbench_sidebar.dart`（新）：品牌、搜索、章节/资料页签、章节目录、资料分组、
  底部保存状态与切换作品；章节行支持右键/长按重命名与归档。
- `lib/workspace/presentation/workbench_chrome.dart`：56px 顶栏；工作标题 + 保存点；查找/讨论记录/讨论这段、
  章节与版本、模型设置、版式（舒适/宽稿）、专注、章节讨论、导出、界面语言、更多（工作区工具）。
- `lib/workspace/presentation/workbench_screen.dart`：`Row(侧栏 + Column(顶栏 + 纸面))`；窄窗抽屉；
  专注隐藏侧栏；`--system-title-bar` 回退。
- `lib/workspace/presentation/workbench_content.dart`：只保留纸面与空态/错误态，移除原 REAL/Rust 状态块。
- `lib/workspace/presentation/manuscript_editor.dart`：32px/600 标题 + 12px 元信息（作品 · 字数）、
  856/1016 纸面排版、章末 撤销/重做/章节讨论、查找浮层；工具动作上移到顶栏。
- `lib/workspace/presentation/editor_action_registry.dart`（新）：编辑器与顶栏的动作桥（查找、讨论、选区）。
- `lib/workspace/presentation/editor_tools.dart`：工作区工具改为可复用的菜单入口（资料/出处/历史/RPG/摘要/
  记忆/导入/旧想法/学习/角色/备份/模型）。
- `lib/window/desktop_title_bar.dart`：恢复 M2-W 可访问性结构（拖动区、工具提示、焦点顺序、44px 目标），
  由 `main.dart` 默认启用；`--system-title-bar` 保留系统标题栏回退。
- `lib/main.dart`：自绘导航栏默认开启，`--window-shell` 兼容旧参数。
- `lib/editor/editor_scene.dart`：选区 `#dce5f4`、光标 `#49659c` 对齐原主题。
- 三份 ARB（en/zh/zh_Hans）新增侧栏/顶栏/元信息文案并重新生成 l10n。

## 4. 响应式与可访问性

- 宽度 ≥ 1120×文字缩放：显示文字标签；不足时切图标 + tooltip。
- 宽度 < 760×文字缩放：只保留查找/讨论/更多，其余动作收进“更多”菜单，避免窄窗溢出。
- 保存状态在窄窗只显示状态点（tooltip 显示文案）。
- 保留 48px 可点击区域与键盘焦点；标题栏按钮维持 44px 目标与既定 Tab 顺序。
