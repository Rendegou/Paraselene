# Flutter 前端工程规范

更新：2026-10-21。适用于 `apps/desktop/lib/**`、`packages/text_contract/lib/**` 的全部自有生产 Dart 代码。生成代码、第三方运行资源、固定 Rust 快照不属于可手工整改范围；`probe/` 是自有代码，仍接受结构检查。测试、工具与脚本接受格式、分析和自身行为测试，不把测试分组入口套用生产函数长度。

## 1. 权威与文档职责

用户明确要求优先。仓库内依次遵守 `AGENTS.md` 的工程/数据边界、本文件的前端规则、`DESIGN.md` 的视觉角色；迁移计划约束既有 Rust/Unicode/存储合同。若这些合同实质冲突，记录具体冲突，不能自行改作者数据合同。

- 本文件定义怎么写代码、怎样证明符合规范；`DESIGN.md` 定义界面外观、状态与允许的角色差异。
- `README.md` 提供入口和命令；`docs/progress.md` 与 evidence 只记录某一工作树的实际结果。
- 带日期的整改计划、研究提案和旧工程设计是历史依据，不能覆盖当前规范或当作已完成的验收。
- 技能提供方法，按当前任务取用；安装技能不等于引入其全部依赖或产品要求。

## 2. 结构与复杂度（F01–F03）

- **F01**：普通函数、方法、具身构造函数及匿名回调，目标不超过 40 个有效行，硬上限 60；Widget 的 `build` 同样适用。声明参数和构造初始化列表不算函数体，但算文件有效行。匿名回调计入自身及外层函数，不能靠嵌套闭包绕过限制。
- **F02**：每个自有生产 Dart 文件最多 400 个有效行。有效行由 analyzer AST 的 token 覆盖源码行计算，排除注释/空行，多行字面量仍计实际覆盖行。必须先满足格式要求，禁止压行、改阈值、忽略路径或增加“历史基线”换绿。
- **F03**：Widget 树按语义拆为命名 Widget 类，以构造参数传数据和动作；不以返回 `Widget` 的 `_buildX` 或换名后的同类方法堆页面。回调式 builder 接口仍可正常使用。不得用 `part` 碎片掩盖大模块，跨文件拆分应有独立职责。
- Views 只组合界面和转发意图；异步协调、变换和可测试业务逻辑进入 controller/service/repository。沿用构造注入与 ChangeNotifier/Listenable，不顺带引入 Riverpod、Drift 或路由框架。
- 私有状态保留在生命周期所有者；拆文件不等于把可变状态公开。值对象的单位、身份、版本与可空性明确，不用 `dynamic` 扩大新接口。

## 3. 主题、排版与布局（F04–F06）

- **F04**：业务代码通过 `WorkbenchTokens`、`WorkbenchControls` 或主题角色使用颜色和文字样式。裸 `Color`/`MaterialColor`、`Colors.*`、`TextStyle` 构造及字体族声明集中在 `lib/theme/`；业务可以用现有文字角色的 `copyWith` 添加局部装饰。不得在业务页面复制调色板。
- 主题默认正文角色服务工具界面；作者稿件显式使用 `WorkbenchTokens.body`，不把 20px 衬线正文设成所有输入框的默认字体。完整字号/行高/层级见 `DESIGN.md`。
- **F05**：通用控件继承共享状态样式，输入显式消费工具字体。可视底板、布局盒、命中区域分开；状态不改变布局。特殊正文锚点只使用 DESIGN 中已有的有限例外。
- **F06**：以可用约束与文字缩放决定目录、工具折叠与滚动，不以设备名决定布局。界面起止方向使用 Directional 几何；`all`/`symmetric` 等方向中性几何可用。作者稿件、画布坐标、原生拖动区域的物理坐标保留其专门合同。
- 不通过缩小字体、钳制缩放、`FittedBox` 或省略核心译文掩盖溢出。所有核心动作在窄窗和 200% 字号下可访问。布局独有的测量值可保留，但通用间距使用 4/8/12/16/24 节奏；不为每个一次性数字造令牌。

## 4. 无障碍、层级与状态（F07–F09）

- **F07**：操作具有名称、启用状态与适当 button/selected/expanded/toggled 语义；优先保留原生控件语义，不给每个装饰节点重复添加朗读。仅图标操作提供本地化 tooltip/可访问名称。选中、错误和运行状态不能只靠颜色。
- 普通及占位文字对比度至少 4.5:1，大字至少 3:1；识别控件/状态所必需的非文本线索至少 3:1。禁用内容、纯装饰分隔线等按适用例外处理，不要求把全部细线加深。主题对比度组合通过测试固定，屏幕阅读器仍需原生验收。
- **F08**：键盘焦点清楚可见，Tab 顺序合理；Escape 每次退出最内层，临时面板关闭后归还焦点。IME composing 时不抢 Enter/Escape 或正文快捷键。隐藏浮层须退出绘制、命中和 Tab，不能只透明。
- **F09**：段下讨论是嵌入表面，不加全屏遮罩；菜单是轻浮层；阻断操作的 Dialog 才使用模态遮罩。每层只承担一次底色/边框/阴影绘制，不叠 Card/Dialog 表面。
- 列表/页面明确处理加载、空、失败和内容；失败给恢复动作。后台刷新尽量保留已显示内容。禁用操作说明真实原因；生成、保存、采纳分别表达，不能伪称尚未具备的能力。
- 即时控件状态可以无动画；新增动画必须在减少动态效果时得到同样的最终状态。

## 5. 异步、资源和原生边界（F10–F12）

- **F10**：Future 必须被 `await`、返回，或以有明确失败归宿的 `unawaited` 启动。`unawaited` 只是所有权声明，不会处理错误；禁止空 `catch`、空 `onError`、`.ignore()` 或空 `catchError` 吞掉失败。需要提前监听的 Future 仍须保存原 Future 并在受控出口统一等待/抛出。
- 每个 await 后使用 State/BuildContext 前核对 mounted；对可能切作品/切章/切线程的任务同时检查身份、版本或代次。取消和迟到响应不可污染新目标。
- **F11**：监听、计时器、FocusNode、输入/滚动控制器和通道句柄有明确所有者和释放路径。释放期异步工作必须报告错误或保存在可观测结果中；关闭失败保持恢复入口，不能丢内存稿。
- **F12**：原生调用通过现有 native gateway/repository；Widget 不新建数据库、网络客户端或 FRB 句柄。Rust 是保存、采纳、版本与正文 hash 权威。保留 UTF-16/Unicode 标量换算、原文 hash、草稿/请求/候选隔离和发送前完整预览确认。
- 失败对用户暴露稳定可本地化错误码；诊断只记录类型/错误码/计数，不记录正文、凭据或私人路径。可以在边界把异常转为失败值，但不能把编程错误伪装成功。

## 6. 本地化和注释（F13–F14）

- **F13**：全部产品界面文案通过 ARB；品牌名、稳定协议值和作者内容不翻译。UI locale、稿件语言和输出语言互相独立。英文模板每键有用途 description，占位符有 type，各 locale 的键和占位符一致；ICU 数量与句序不靠字符串拼接。
- 文案迁移不得修改作者正文/示例 Unicode 合同，不能手改 gen-l10n/FRB 输出。生成应使用固定环境并校验 freshness。
- **F14**：遵守 [中文注释规范](comment-style-20261020.md)。新文件头写职责/依赖/不变量，公开 API 说明契约与副作用；已有准确英文注释可以保留。注释不替代命名和测试。

## 7. 统一检查与交付

在仓库根目录使用 PowerShell 7：

```powershell
pwsh -NoProfile -File scripts/check-frontend.ps1
pwsh -NoProfile -File scripts/check-frontend.ps1 -Test
```

默认入口检查 AST 结构/主题边界、严格 ARB 元数据、格式和静态分析；`-Test` 再跑普通回归。工具离线依赖恢复和其他可选验证参数见 README 与脚本帮助。缺工具、未恢复依赖或检查失败必须非零退出，不得静默跳过。

- 机器检查覆盖 F01/F02/F03/F04 及 analyzer 的异步/空 catch 等诊断；语义、焦点、层级、身份/版本和资源所有权还必须通过相关行为测试与 review。
- 对结构重构复跑受影响行为和普通全量；涉及几何/主题时，增加少量有实际断言的状态/对比度检查，并在固定字体、常规/窄窗/200% 下集中复看。
- golden 使用固定环境单独运行，不自动 `--update-goldens`。历史失败必须保留并报告；截图生成成功不等于视觉回归比较通过。
- Windows IME、物理 DPI/多屏、系统窗口、屏幕阅读器和净机安装单独记录。模拟键盘、widget enterText、repository fake 不能代替它们。
- 交付列出实际源码范围、命令/退出码、数量、失败与未测项和证据；通过某一组检查只写该组 PASS，不写“全产品/所有原生场景通过”。

外部数值依据：[WCAG 2.2 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。这些是本项目采用的可访问性基线，不把 Web 专用 API 生搬到原生 Flutter。
